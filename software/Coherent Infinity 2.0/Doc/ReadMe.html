Installation

This procedure describes how to upgrade an OS/2 installation to 32-bit Windows (95 or NT4.0). The procedure for a new installation is similar, except that all of the necessary configuration and calibration files are shipped with the new software. For a new installation, users should skip steps 1 and 3 below.

1. Back up existing calibration information.

New users should skip this step.

On the existing OS/2 computer, locate the OS/2 directory that contains the Infinity program. In this directory you will find a number of files with extension *.in. These files contain the calibration, shot count, and configuration information for the laser. Copy all of these files except for FAULTHLP.IN, CONFIG.IN, and WINDOWS.IN to a floppy disk (or any other backup medium).

2. Install the Windows program.

On the new Windows computer, make a directory for the Windows Infinity program and copy (or unzip) all of the program files into it (reference: distribution file list).

3. Copy the calibration files into the program directory.

New users should skip this step.

Copy all of the *.in files that you saved in step 1 into the new program directory created in step 2.

4. Run the Infinity program by double-clicking on the Infinity.exe program icon.

For convenience you can use standard operating system procedures to make a program group or create a shortcut to Infinity.exe.

Changes from the OS/2 Version

  1. The main control panel button for "Servo" has been replaced by "About," which opens an About dialog. The Servo window can be accessed through a pull down menu in the Service window.
  2. It is now possible to disable access to the Service window by deleting or renaming the file Service.txt in the Infinity program directory. If this file is not present when the "Service" button is pressed, the program will not open the window.
  3. There is no longer a separate "demo" version of the program. If the program is run from a command line by typing:
    >infinity run
    the program will run in demo mode.

Known limitations

  1. Win95: Fonts on the Service window A/D channel list is sometimes not set properly. When the program is run from a command line the font is always correct, but when it is run by double-clicking its icon the font will sometimes be too wide.
  2. Win95: Command line argument "demo" is ignored. Program always starts in RS232 mode regardless of any command line arguments.
  3. Windows NT 4.0: The program has been observed to hang completely on startup when the machine's serial port drivers were not properly configured. In this state the program did not respond to mouse events and did not redraw its windows after they were covered by another application. The program can only be stopped using the NT Task Manager. The problem was not actually within the Infinity software but with the system's serial ports; however the behavior of the program made this difficult to determine.

DDE Programmer's Notes

This version of the Infinity program is a fully functional DDE server capable of communicating with other Windows applications. This section describes the protocol used and is intended to support application programming. It assumes a familiarity with Windows DDE concepts and terminology. For further information, see the Microsoft Windows Software Development Kit (SDK) help or an equivalent reference source.

Infinity acts as a DDE Server supporting a single application/topic pair:

Application: 'Infinity'
Topic: 'Control'

To start the Infinity DDE server, open the Application window and select the DDE item from the Remote pull-down menu. Before commands can be sent to Infinity, the client program must obtain the window handle of the Infinity DDE server. This is accomplished by means of a WM_DDE_INITIATE message containing the application/topic pair ('Infinity'/'Control') just given.

Once communication is established, Infinity processes DDE transactions of type WM_DDE_REQUEST. This message takes two parameters:

Format: The only supported format type is CF_TEXT.
Item: A string containing the command to be sent to Infinity. The strings are identical to the RS-232 commands as documented in the Infinity User's Manual. A terminating CR/LF is not required.

In response, Infinity sends a DDE transaction of type WM_DDE_DATA back to the client window. The returned item has a format type of CF_TEXT. The content of the responses is the same as for RS-232 commands, and is documented in the Infinity User's Manual.
